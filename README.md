# Madhya Pradesh Urban Growth Conclave 2.0

Static one-page site and registration page. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

- `index.html` — the public page
- `register.html` — registration

The registration form checks the same fields as before and shows a reference number in the browser. It does not send the entry to a server.
